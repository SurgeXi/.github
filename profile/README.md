# SurgeXi Business Intelligence

**AI operations software that gives professionals more capacity — not more headcount.**

SurgeXi builds secure, human-in-the-loop AI systems that take on the repetitive,
high-volume, easy-to-miss work inside a business: intake, classification, follow-up,
routing, document handling, exception detection, and approvals. A **platform core +
vertical packs + connector layer**, with auditability and tenant isolation built in —
and a human gate in front of every action that can cause harm.

*A TeamSmith Enterprises LLC company (Alabama, USA).*

### Products

Each product below is marked **available**, **in launch**, or **in build**, so you always
know what you can run today versus what's on the way.

#### Vertirite — *available*
A vendor-neutral **AI-governance control plane** you run on your own hardware. It
discovers every AI, bot, and automation already touching your systems, ranks what they
can reach, and puts a human approval gate — plus egress, credential, and
irreversible-action chokepoints — in front of the actions that can hurt you. Every
decision is signed, audited, and reversible; the control plane itself runs air-gapped,
with no model inside it to jailbreak.
→ [vertirite.com](https://vertirite.com)

#### Ma'at Codex — *in launch*
A **verified-knowledge engine** for regulated professions. Every citation it returns is
checked against primary authority — real source, verbatim quote — or it honestly
abstains. There is no code path that emits an unverified citation. Built for fields like
law, tax, and medicine, where a fabricated citation is a real-world liability.
→ [maatcodex.com](https://maatcodex.com)

#### Reconcera — *in launch*
The **accounting and bookkeeping** operations product: AI that handles document intake
and collection, categorization support, client follow-up, and close/deadline discipline
for practices — with the practitioner in the loop at every review and approval point.

#### Surge Edge — *in build*
Security and operational coverage for homes and small businesses, delivered on a secured
on-node appliance.
